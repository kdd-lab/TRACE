What is TRACE? It is a visual analytics interface designed to explain the decision-making processes of AI models on tabular data, showing the contribution of each feature in relation to the data distribution. It facilitates the interpretation of model predictions by showing Rules (why a decision was made) and the Counter-rules (what should change to obtain a different outcome).

About TRACE Interface

To generate these explanations, TRACE allows the combined exploration of feature importance and rule-based explanations. Among the various algorithms for rule-based explanations, TRACE integrates the LORE (Local Rule Explanator) [DOI] algorithm. LORE is a model-agnostic method that analyzes the behavior of any opaque "black box" model by generating a synthetic neighborhood of data to build a transparent surrogate model (like a Decision Tree). This process allows us to extract:

  • Rules: Sequences of conditions (predicates) that explain why a decision was made on a local instance.
  • Counter-rules: Indications of what variations in the input features would lead to a different predicted outcome.
  • Feature Relevance: Measures of how much each feature contributes to the decision-making process.

How to read the interface

To help you explore the explanation, TRACE uses a progressive disclosure workflow. The interface consists of five steps that you can navigate using the colored dots or arrows on the top left corner of the menu.

Key visual elements

  1. Rules (Yellow Indicators)
    These highlight the conditions and feature values for which the current classification holds.
  2. Counter-rules (Purple Indicators)
    These suggest the changes required for the instance to receive an alternative classification.
  3. Distributions
    For numerical data, a curve shows the distribution from the training dataset, with a black vertical line marking your specific instance.

    Categorical data is shown via stacked bar charts, highlighting current instance value.
  4. Feature Importance Bars
    Located on the right side, these bars indicate the importance of each feature to the decision. They can be used as a sorting mechanism of the visualization.

Customizing your view

The Menu Panel on the left allows you to adapt the interface to your visual preferences and analytical needs:

  • Walkthrough Tutorial: You can view punctual information about each section by clicking on the Info button and navigating with the arrows.
  • Color Themes: You can switch between Light and Dark modes using the intuitive icons.
  • Accessibility: A dedicated color-blind-friendly palette is available to ensure clear differentiation of all interface elements.
